# Módulos Foundry do Teuri (site)

Showcase and tutorials for Teuri's Foundry VTT modules. Plain HTML/CSS/JS, no build, hosted on GitHub Pages.

- Edit `data/modules.js` to add or update a module (single source of truth).
- Run `node tools/check-site.mjs` to validate the data.
- Open `index.html` in a browser to preview; no server needed.
- Push to `main`: GitHub Pages publishes the repository root.

Visual identity: Dados Críticos kit 2026 (logo and background pattern in `assets/`).
